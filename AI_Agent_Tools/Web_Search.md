# Web Search

## Quick Overview

| Name           | Definition                                                      | Example                                  |
| -------------- | --------------------------------------------------------------- | ---------------------------------------- |
| Web Search     | Allows an AI agent to find fresh information from the internet. | Searching for the latest AI developments |
| Search Query   | The words or question sent to a search engine.                  | `latest AI developments`                 |
| Search Results | Pages returned by the search engine.                            | News articles, documentation, websites   |
| Source         | A webpage used to support the agent's answer.                   | Official documentation or a news website |

## 1. Web Search

**Definition:** Web search allows an AI agent to find and use current information from the internet.

**Example:**

```text
User: What are the latest AI developments?

Agent:
1. Creates a search query.
2. Searches the web.
3. Reads relevant results.
4. Summarizes the useful information.
5. Provides the answer with sources.
```

**Instructions:**

* Use web search when information may be new, changing, or missing from the model's existing knowledge.
* Give the agent a clear search goal so it can find relevant information.
* Ask the agent to include sources so the information can be verified.
* Cross-check important information because search results can contain incorrect, biased, or low-quality content.

## 2. Search Query

**Definition:** A search query is the words or question an agent sends to a search engine.

**Example:**

```text
User request:
"What are the latest AI developments?"

Search query:
"latest AI developments"
```

**Instructions:**

* Use specific keywords to improve search results.
* Include important details such as a topic, date, or location when needed.
* Avoid overly broad queries.
* The agent may create or modify the query based on the user's request.

## 3. Search Results

**Definition:** Search results are the webpages returned by a search engine after a query.

**Example:**

```text
Search: "latest AI developments"

Results:
- AI company announcement
- Technology news article
- Research paper
- Official documentation
```

**Instructions:**

* Review multiple relevant results when accuracy matters.
* Prefer reliable and authoritative sources.
* Do not assume the first result is always correct.
* Filter out irrelevant or misleading pages.

## 4. Sources

**Definition:** Sources are the webpages or documents used to support the information in an agent's answer.

**Example:**

```text
Answer:
GPT-5.6 was released with new capabilities.

Source:
Official OpenAI documentation
```

**Instructions:**

* Include sources when possible.
* Prefer primary sources such as official documentation and original research.
* Use multiple sources for important claims.
* Sources make answers easier to verify and trust.

## Quick Memory

```text
Web Search → Find fresh information from the internet
Search Query → Question sent to the search engine
Search Results → Webpages returned by the search engine
Source → Information used to support the answer
```
