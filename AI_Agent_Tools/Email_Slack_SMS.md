# Email / Slack / SMS

## Quick Overview

| Name  | Definition                                                            | Example                               |
| ----- | --------------------------------------------------------------------- | ------------------------------------- |
| Email | A channel for sending detailed messages, reports, files, and updates. | Send a daily report to a manager.     |
| Slack | A team communication channel for messages, alerts, and collaboration. | Send an alert to a development team.  |
| SMS   | A text-message channel for short, time-sensitive notifications.       | Send a login or appointment reminder. |

## 1. Email

**Definition:** Email lets an AI agent send detailed messages, reports, files, and updates to users.

**Example:**

```text
AI Agent → Generate daily sales report → Send it by email
```

**Instructions:**

* Use email for detailed information or messages that users may need to save.
* Include files or reports when necessary.
* Use clear subjects so important emails are easy to identify.
* Make sure the agent has permission to send emails.

## 2. Slack

**Definition:** Slack lets an AI agent communicate with people inside a team workspace.

**Example:**

```text
AI Agent → Detect server error → Post alert in #engineering
```

**Instructions:**

* Use Slack for team communication, alerts, and quick updates.
* Send messages to the correct channel or user.
* Keep messages short and relevant.
* Make sure the agent has permission to access the required workspace or channel.

## 3. SMS

**Definition:** SMS lets an AI agent send short text messages directly to a user's phone.

**Example:**

```text
AI Agent → Detect appointment tomorrow → Send SMS reminder
```

**Instructions:**

* Use SMS for short and time-sensitive notifications.
* Keep messages concise because SMS is designed for short text.
* Get the user's permission before sending messages.
* Avoid sending sensitive information through SMS unless appropriate security measures are in place.

## Quick Memory

```text
Email → Detailed messages and reports
Slack → Team communication and alerts
SMS → Short, time-sensitive notifications
```
